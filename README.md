# FlowDesigner

データ（テーブル／ファイル）と機能（処理）のつながりをマウスで描く作図ツール。
**`FlowDesigner.html` をダブルクリックしてブラウザで開くだけ**で動きます（インストール・通信なし）。

## ノードの種類（業務システム向け）

| 区分 | 種類 | 持てる情報 |
|---|---|---|
| 処理（CRUD表の行） | 画面 | ID（SCR-010）／呼び出し元（メニュー階層）／画面項目 |
| | 機能 | ID／説明 |
| | バッチ | ID（BAT-101）／起動タイミング（毎日2:00 など） |
| | API | ID／エンドポイント（POST /api/orders） |
| データ（CRUD表の列） | テーブル | 物理名（T_JUCHU）／項目 |
| | ファイル | 配置先（\\\\server\\share\\out） |
| | 帳票 | ID（RPT-021）／出力項目 |
| その他 | 外部 / メモ | 利用者・他システム、補足 |

種類は右パネルの「種類」でいつでも変更できます。

## 使い方

| やりたいこと | 操作 |
|---|---|
| ノードを追加 | 上部ボタン（画面／機能／バッチ／API／テーブル／ファイル／帳票／外部／メモ）、または背景をダブルクリック |
| 線でつなぐ | 枠にカーソルを乗せると出る **○** から相手の枠へドラッグ（空白で離すと機能ノードを作ってつなぐ） |
| 画面遷移を描く | **画面どうし**をつなぐと自動で画面遷移（水色の線）になり、契機・条件を入力できる。他の線も右パネルの「線の種別」で遷移に変更可 |
| 自動整列 | **自動整列**ボタン（`Ctrl+L`）→ 横（左→右）／縦（上→下）を選ぶ。線のつながりから段に分けて並べ替え、戻り線は外側に回します。表示中のものが対象（複数選択中はその分だけ）。`Ctrl+Z` で元に戻せます |
| 表示を絞る | 上部の選択で **画面遷移だけ** / **データの流れだけ**。SVG・PNGは表示中のものだけ書き出されるので、1枚の図から画面遷移図とデータフロー図を作れます |
| 名前を変える | 枠をダブルクリック、または右パネル |
| ID・タイミング・項目 | ノードを選び、右パネルで入力（IDは枠の右上に表示） |
| CRUDを付ける | 線を選び C/R/U/D を押す（線上に `[RU]` と表示） |
| 複数選択 | Shift+クリック、Shift+背景ドラッグ（選択後は揃え・等間隔） |
| 画面移動 | 背景ドラッグ＝スクロール、ホイール＝拡大縮小、Shift+ホイール＝スクロール |

ショートカット: `Del` 削除 / `Ctrl+D` 複製 / `Ctrl+A` 全選択 / `Ctrl+L` 自動整列 / `Ctrl+Z` 元に戻す /
`Ctrl+Y`（`Ctrl+Shift+Z`）やり直し / `Ctrl+S` JSON保存 / `Ctrl+O` 開く / `Ctrl+0` 全体表示 /
矢印キー 10px移動（Shift併用で1px）

## 保存と書き出し

- 編集内容はブラウザ（localStorage）に**自動保存**。閉じても次回そのまま開きます。
- **保存(JSON)** … 図をファイルとして保存。**開く** で読み込み（別PCでも同じ）。
- **SVG / PNG** … 設計書や資料に貼る用の画像を書き出し。
- **画面遷移表** … 遷移元 / 契機 / 条件 / 遷移先 の一覧を自動生成（CSV・コピー可）。行をクリックするとその線を選択します。
- **CRUD表** … 処理（画面/機能/バッチ/API）× データ（テーブル/ファイル/帳票）の一覧表を自動生成。
  **CSV書き出し**／**タブ区切りコピー**でそのままExcelに貼れます
  （CRUD未設定の線は向きから推定: データ→処理=R、処理→データ=U）。

## JSONの形

```json
{
  "schema": 1,
  "title": "受注登録の流れ",
  "nodes": [
    {"id":"n1","type":"table","name":"受注ヘッダ","x":560,"y":30,"w":200,"h":120,
     "code":"T_JUCHU","fields":["受注番号","得意先コード"],"desc":"","color":"#2563eb"},
    {"id":"n2","type":"batch","name":"夜間締め処理","x":280,"y":240,"w":200,"h":86,
     "code":"BAT-101","timing":"毎日 2:00","desc":"受注を集計し帳票を作成"}
  ],
  "edges": [
    {"id":"e1","from":"n1","to":"n2","fromSide":"r","toSide":"l","kind":"data",
     "label":"登録","crud":["C","U"],"dashed":false,"bidir":false},
    {"id":"e2","from":"n3","to":"n4","kind":"transition",
     "label":"［登録］ボタン","cond":"入力エラーなし"}
  ]
}
```

- `type`: `screen` / `function` / `batch` / `api` / `table` / `file` / `report` / `external` / `note`
- `code`: ID・物理名、`timing`: 起動タイミング等（種類により意味が変わる）、`fields`: 項目
- `kind`: `data`（データの流れ）/ `transition`（画面遷移）。省略時は画面どうしなら遷移、それ以外はデータ扱い
- 画面遷移の線は `label` が契機（ボタン・操作）、`cond` が条件
- `fromSide` / `toSide`: `t` `r` `b` `l`（null なら自動で近い辺に接続）

テキスト形式なので、他ツールからの生成や差分管理もできます。
